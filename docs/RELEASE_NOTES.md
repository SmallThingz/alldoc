# 0.1.1 preview

- Spreadsheet edits now join the recoverable draft as you type, preventing Back, another cell, sheet changes or opening another document from silently dropping them.
- Done closes the cell editor; Revert confirms before restoring its previous value.
- Find focuses the search field; Back closes search before leaving the document.
- Text editor fields have contextual accessibility labels and a minimum 48dp height.

This remains a development-signed preview. PDF forms are research only, not a supported feature. Real-device/keyboard/TalkBack and full office-format fidelity limitations remain unchanged. The prior 0.1.0 preview artifact is retained.
