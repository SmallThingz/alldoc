# UI evidence

`v0.2/` contains the redesigned application's latest native Compose captures, produced with Robolectric native graphics on API 35. Root PNGs and `navigation/` are historical 0.1.x captures and are not current design evidence.

The narrow/large-font images use simulated IME insets, not a real keyboard. These captures do not establish Android WebView layout, isolated native PDF runtime behavior, or physical-device behavior. See `../VERIFICATION.md` for exact test boundaries.
